# 🚀 Laravel + React Starter Template

A **ready-to-use Laravel + React starter project** designed for rapid development and clean architecture.

This template comes pre-configured with:

- ⚡ **Laravel Breeze** for authentication (login, registration, password reset)
- 🧩 **Spatie Laravel Permission** for powerful role and permission management
- ⚙️ Pre-set **API + React frontend** structure for smooth integration

---

## 🛠️ Features

- Laravel 11 backend with RESTful API structure  
- React 18 frontend (Vite powered)  
- Authentication and session handling using Laravel Breeze  
- Role & permission management using Spatie  
- Clean folder structure for faster setup and scalability  
- Ready for Docker or local development
